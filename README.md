# SmartFarm Project

Indoor multi-shelf smart farming system using ESP32, sensors, and ROS 2 / micro-ROS.

## Overview
- Multi-shelf setup with soil moisture, light, and temperature/humidity sensors
- ESP32-based control of 12 V fans and water pumps
- Wi-Fi, OTA updates, and micro-ROS/ROS 2 integration for monitoring and control

## Repository Structure
- `firmware/` – ESP32 code (PlatformIO / Arduino)
- `hardware/` – schematic, wiring, and parts list
- `docs/` – photos, wiring diagrams, architecture
- `logs/` – example sensor logs
